# Одометр

Учёт расходов на автомобиль: заправки, ТО, ремонты, документы, напоминания, аналитика.

**Демо:** https://igorasha26.github.io/odometer/

## Стек

- React 18, TypeScript, Vite 5
- React Router 6
- Dexie (IndexedDB)
- lucide-react — иконки
- Свой CSS на переменных (светлая/тёмная темы), без UI-библиотек
- Vitest, Testing Library, fake-indexeddb, jsdom
- PWA: манифест и service worker
- GitHub Actions + GitHub Pages

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # тесты
npm run build    # production-сборка в dist/
```


## Что работает

**Обзор.** Сумма за период, стоимость километра, средний расход, текущий одометр и пробег в месяц.
Столбцы расходов по месяцам, кольцевая диаграмма по категориям, динамика расхода топлива,
ближайшие напоминания, последние записи. Период переключается: месяц / 3 месяца / полгода / год / всё время.

**Расходы.** История с фильтром по категориям и поиском, добавление, редактирование, удаление,
экспорт в CSV (точка с запятой и BOM — Excel с русской локалью открывает корректно).

**Форма записи.** Категории плитками с иконками. Для топлива: литры, цена за литр и сумма связаны —
пересчитывается то поле, которое правили раньше остальных, поэтому правка цены на заполненной
форме двигает сумму, а не наоборот. Для запчастей и ремонта: что меняли и где.
Пробег подставляется последний известный. Пробег назад или дата в будущем — предупреждение
с возможностью подтвердить, а не запрет.

**Обзор.** График по месяцам всегда показывает год, независимо от выбранного периода:
нужен фон, на котором виден выбранный месяц. «В среднем в месяц» считается за всё время
владения машиной, а не за период. Структура расходов — в рублях; при наведении на сегмент
кольца в центре появляется его сумма, а строка списка подсвечивается.

**Периоды.** Календарные, а не скользящие: «Месяц» — это текущий месяц с первого числа,
«3 месяца» — три календарных месяца. Рядом кнопка своего диапазона с двумя календарями.
Клик по столбцу в «Расходах по месяцам» сужает весь обзор до этого месяца, повторный — снимает.

**ТО.** Интервал задаётся при добавлении машины, и форма сразу показывает, на каком пробеге
делать следующее. В гараже видно, когда было последнее ТО («2 месяца назад, на 145 000 км»)
и где следующее. Пробег в форме расхода обязателен только для ТО — именно от него идёт отсчёт;
в остальных записях его можно не вводить, подставится последний известный.

**Документы.** Даты окончания ОСАГО, КАСКО, диагностической карты. Видно, сколько дней осталось,
просроченные подсвечены. Продление сдвигает дату от прежней, а не от сегодняшней,
иначе за годы набегает сдвиг.

Документы и расходы связаны в обе стороны: при добавлении документа можно указать
уплаченную сумму — она попадёт в расходы категорией «Документы»; и наоборот, запись
в этой категории предлагает завести срок, чтобы про полис не забыли.

**Гараж.** Несколько автомобилей, расходы и пробег в карточке каждого, удаление вместе с записями.
Машина выбирается выпадающим списком в шапке любого экрана.

**Настройки.** Свои категории с типом, цветом и иконкой; системные скрываются, но не удаляются.
Экспорт и импорт резервной копии в JSON.

**Обзор настраивается.** Кнопка с иконкой сетки в шапке включает режим перестановки:
блоки таскаются мышью или двигаются стрелками (на телефоне HTML5 drag не работает).
Порядок сохраняется. Новые блоки приложения уходят в конец, исчезнувшие отбрасываются.

## Структура

```
src/
  entities/      типы домена, системные категории
  repository/    доступ к данным: интерфейс + реализация на Dexie
  shared/lib/    расчёты топлива и статистики, напоминания, деньги, CSV, валидация, демо-данные
  shared/ui/     модалка, диалоги, графики, иконки
  pages/         экраны
  app/           store активного автомобиля, роутинг
  styles/        theme.css — токены и компоненты; app.css — раскладка
```
